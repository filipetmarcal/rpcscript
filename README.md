# rpcscript
Sistema de RPG de cartas adaptado para console

---

## 🖥️ Interface

RPC-Script é projetado para rodar em:

- terminal local
- SSH
- ambientes educacionais
- servidores
- futuros frontends gráficos

A interface **não altera as regras**, apenas as representa.

---

## 🧩 Modularidade

O RPC-Script foi feito para ser expandido por:

- módulos de gênero
- módulos narrativos
- módulos de economia
- módulos de combate
- módulos experimentais

O **core nunca é alterado**.
